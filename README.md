# 聚合解析 (DouyinJieXi)

一款基于 Android + Jetpack Compose 的**多平台无水印视频 / 图集解析下载**工具。粘贴分享链接即可解析并下载无水印视频、图集（含实况图），同时支持 QQ 音乐 / 网易云音乐的搜索、在线试听与下载。

## ✨ 功能特性

- **多源聚合 + 智能容灾 Fallback**：内置多套第三方解析源，带 Key 高并发通道优先，失败自动降级到免 Key 兜底源；支持「数据缝合」，将一个源的作者/统计补全到另一源的媒体数据上。
- **多平台无水印解析**：抖音、快手、小红书、豆包、B 站，以及经聚合源支持的更多平台；支持短链自动展开（含带文字口令的分享链接）。
- **音乐解析 + 在线试听**：QQ 音乐（链接/ID）、网易云（关键词搜索 + 多音质）；取直链、在线试听、下载。
- **AI 错误分析**：解析失败时可一键调用大模型，用通俗语言解释原因并给出建议。
- **自建更新通道**：启动自动检查新版本，服务器端 `update.json` 版本比对，支持强制更新与国内/海外双下载链路。
- **智能下载**：视频/图片/音乐按类型存入相册对应目录（Movies / Pictures / Music），支持自定义子文件夹。
- **内置调试日志**：设置页可查看最近 200 条运行日志，便于排查 Fallback / 缝合流程。

## 📱 使用说明

1. 在「视频/图文」页粘贴抖音 / 快手 / 小红书 / 豆包 / B 站的分享链接（支持整段带文案的分享文本，自动提取链接）
2. 点击「解析」，等待返回作品信息（标题、作者、点赞/评论等）
3. 按内容类型：视频「下载视频」、图集「下载全部图片」、实况可逐张预览下载
4. 切到「音乐下载」：QQ 音乐贴链接/ID，网易云搜关键词选音质；结果卡片下方可直接**在线试听**
5. 「设置」中可开关解析接口、改下载子文件夹、切背景、看运行日志、用 AI 分析

> 下载默认存到公共目录下 `DouyinJieXi` 子文件夹，可在设置中修改（仅字母/数字/下划线）。

## 🛠️ 技术栈

- Kotlin · Jetpack Compose · Material 3
- OkHttp / Gson
- Media3 (ExoPlayer) · Coil
- DataStore
- AGP 9.2 + Gradle 9.4.1，minSdk 24，targetSdk 36

## 🔨 构建

环境要求：Android Studio + JDK 17+。打开项目根目录 Sync 后运行：

```bash
# 正式包（在 keystore/ 配置 release 签名后会自动使用；否则回退 debug 签名）
./gradlew assembleRelease

# 调试包
./gradlew assembleDebug
```

产物位于 `app/build/outputs/apk/<variant>/`。
