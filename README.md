# 聚合解析 DouyinJieXi

一款基于 Android + Jetpack Compose 的多平台聚合解析下载工具。粘贴分享链接即可解析并下载无水印视频、图集（含实况图），同时支持 QQ 音乐 / 网易云音乐的搜索、解析与下载。

## ✨ 功能特性

- **多平台解析**：抖音、快手、小红书、豆包，支持短链接自动展开
- **多接口智能容灾（Fallback）**：抖音解析内置 6 个解析接口，逐个尝试，接口异常自动切换；支持在设置中单独开关每个接口
- **数据缝合**：当接口 A 返回媒体数据、接口 B 返回作者/统计数据时，自动合并出最完整的结果
- **实况图支持**：抖音实况（Live Photo）可预览并单独下载每一帧视频
- **音乐下载**：QQ 音乐（链接/ID 解析）、网易云音乐（关键词搜索 + 多音质选择：标准/极高/无损/Hi-Res 等）
- **智能下载**：视频/图片/音乐按类型自动保存到相册对应目录（Movies / Pictures / Music），支持自定义子文件夹
- **AI 错误分析**：解析失败时可一键让 AI 用通俗语言解释报错原因（SiliconFlow Qwen3-8B）
- **应用内更新**：启动时自动检查新版本，支持国内外双下载通道智能切换
- **内置调试日志**：设置页可查看最近 200 条运行日志，便于排查 Fallback / 缝合等流程

## 📱 使用说明

1. 在 App 的「视频/图文」页粘贴抖音 / 快手 / 小红书 / 豆包的分享链接（支持直接粘贴整段带文案的分享文本）
2. 点击「解析」，等待返回作品信息（标题、作者、点赞/评论数据等）
3. 根据内容类型：
   - **视频**：点击「下载视频」保存到 `Movies/<子文件夹>/`
   - **图集**：点击「下载全部图片」批量保存到 `Pictures/<子文件夹>/`，或长按单张图片单独下载
   - **实况**：可逐张预览并下载实况视频
4. 切换到「音乐下载」Tab：
   - **QQ 音乐**：粘贴歌曲链接或歌曲 ID
   - **网易云音乐**：输入关键词搜索，选中歌曲后选择音质下载；也可直接粘贴歌曲链接/ID
5. 在「设置」中可：开关抖音各解析接口、修改下载子文件夹名称、切换背景图、查看运行日志、使用 AI 分析

> 下载路径默认位于公共目录下的 `DouyinJieXi` 子文件夹，可在设置中修改（仅支持字母、数字、下划线）。

## 🛠️ 技术栈

- Kotlin 2.2 + Jetpack Compose + Material 3
- OkHttp / Gson（网络请求与 JSON 解析）
- Media3 ExoPlayer（视频播放）
- Coil（图片加载）
- DataStore（设置持久化）
- AGP 9.x，minSdk 24，targetSdk 36

## 🔨 构建

使用 Android Studio（或命令行 Gradle）打开项目根目录，同步后直接构建运行即可：

```bash
# 命令行构建 Debug 包
./gradlew assembleDebug
```

## 🔑 本地密钥配置（必须）

本项目的两个第三方接口 Key **不会提交到代码库**，而是从本机的 `local.properties`（已被 `.gitignore` 忽略）读取，通过 BuildConfig 注入。**不配置以下 Key，小红书解析和 AI 错误分析功能将不可用**（其余解析不受影响）。

在项目根目录的 `local.properties` 中追加（如果文件不存在则新建）：

```properties
# 小红书解析接口 Key（apibyte 平台，必配，否则小红书无法解析）
XHS_API_KEY=你的小红书解析Key

# AI 错误分析接口 Key（SiliconFlow 平台，必配，否则设置页的 AI 分析不可用）
AI_API_KEY=你的SiliconFlowKey
```

配置后重新构建即可生效。请勿将 `local.properties` 提交到版本库。
